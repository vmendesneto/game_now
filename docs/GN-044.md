# GN-044 — comparação de modelos Whisper (preparação independente)

Esta entrega prepara a medição **local e reprodutível** de `tiny`, `base`, `small` e `medium` em CPU Windows e, se houver CUDA compatível, GPU. Não constitui o benchmark físico completo exigido por GN-044, portanto sua checkbox permanece **[ ]** até haver medições reais, áudio permitido e referência humana independente.

O script reutiliza `CPUTranscriber`/GN-040 para CPU e a normalização/Levenshtein de palavras usada na GN-083 para o cálculo WER. Para CUDA, usa o mesmo faster-whisper, decodificação WAV de 16 kHz e parâmetros de inferência. Cada modelo é executado em **um processo isolado**, reduzindo a contaminação da RAM pelos pesos do modelo anterior.

## Preparação

Instale a dependência ASR opcional (GN-083 já fixou PyAV compatível):

~~~powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-asr.txt
~~~

Crie um `manifesto044.json` local, **não versionado**, com até oito amostras WAV PCM mono s16le 16 kHz de até 30 s cada, de uso autorizado, e transcrições de referência anotadas manualmente (não copiadas do Whisper):

~~~json
[
  {"wav": "amostra1.wav", "reference_text": "A bola está com o atacante pelo lado direito"},
  {"wav": "amostra2.wav", "reference_text": "O árbitro marcou impedimento"}
]
~~~

Os caminhos dos arquivos WAV são relativos à pasta do manifesto (ou absolutos). O programa nunca consulta YouTube, rádio ou Internet para captar áudio e não salva nem imprime o texto reconhecido. **O faster-whisper pode baixar pesos do modelo** se eles não estiverem no cache; faça isso apenas em ambiente permitido.

### CPU — Prompt de Comando do Windows

~~~bat
.\.venv\Scripts\python.exe -m scripts.benchmark_gn044_whisper --manifest manifesto044.json --models tiny base small medium --device cpu --cpu-threads 2 --beam-size 3 --permission-confirmed --output relatorio044-cpu.json
~~~

### GPU NVIDIA — somente quando CUDA/CTranslate2 compatíveis estiverem instalados

~~~bat
.\.venv\Scripts\python.exe -m scripts.benchmark_gn044_whisper --manifest manifesto044.json --models tiny base --device cuda --permission-confirmed --output relatorio044-gpu.json
~~~

CUDA é uma opção a testar, **não** algo já validado. Mac Metal não está implementado nesse benchmark.

## Medidas e limites

Cada modelo registra WER total (soma da distância de edição de palavras dividida pelo total de palavras de referência), total de palavras/erros, latência por amostra (mediana e p95), segundos de áudio, custo de inferência por segundo de áudio, tempo de parede incluindo carregamento inicial, CPU do processo e pico de RAM residente (RSS/working set do processo; Windows via Win32, Linux/macOS via `resource`). Medições de GPU **não incluem VRAM**. No CPU, configuração `int8`; GPU `float16`. O primeiro período medido inclui inicialização lazy do Whisper, portanto compare modelos no mesmo computador/carga/entrada e reporte o hardware.

WER é precisão de **texto reconhecido**, não qualidade de equipe/jogador/região, que exige as métricas GN-083. Um teste com narração artificial não representa rádio real; executar com referência real autorizada e registrar ambiente, duração, número de amostras, latência e RAM em Windows para concluir GN-044.

O processo filho de cada modelo pode demorar e ocupar bastante RAM. Se um falhar, o comando interrompe a comparação e não afirma sucesso parcial como benchmark completo. A saída JSON contém somente estatísticas, sem PCM, URLs ou transcrição reconhecida.

A CI executa apenas mocks para validar a instrumentação e o cálculo de WER; não baixa modelos nem faz inferência de áudio real neste roteiro. GN-083 e GN-085 continuam pendentes.
