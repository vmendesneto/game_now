# ADR-0001 — Arquitetura inicial e limites do MVP

**Data:** 2026-11-10  
**Situação:** aceita para a primeira implementação; revisável conforme medições no Windows.

## Contexto

Uma partida é acompanhada por diversas narrações com publicidade e atrasos. O projeto precisa de demonstração offline, ingestão de áudio somente no servidor e posições estimadas por linguagem, nunca por rastreamento visual.

## Decisões

1. **Backend:** Python 3.11/3.12 com FastAPI e Pydantic v2, sem requisito de serviço pago. WebSocket transmite somente dados.
2. **Front:** HTML/CSS/JavaScript e SVG inicialmente, sem build Node obrigatório. Pode ser migrado para React sem alterar contrato.
3. **Contrato:** schema JSON v1 derivado de modelos Pydantic, IDs estáveis, timestamps com timezone, zonas 5×3 relativas ao ataque da equipe observada; desconhecido é null.
4. **Modo demo:** texto e eventos sintéticos locais; nenhuma requisição de mídia ou modelo de IA. Não equivale a análise de rádio real.
5. **Armazenamento futuro:** SQLite para partidas, fontes, transcrições e eventos. Em memória somente para a demonstração inicial.
6. **Captação futura:** FFmpeg para rádio, yt-dlp apenas para vídeos públicos legitimamente acessíveis. Não contornar DRM, paywall ou login.
7. **ASR futuro:** faster-whisper em job separado, CPU primeiro; modelos e benchmarks Windows selecionados somente após teste.
8. **Fusão futura:** identificador canônico por evento, IDs de observações de origem, relógio lógico e expiração de zona não confiável.
9. **Rede:** bind somente 127.0.0.1 por padrão. Acesso LAN/Internet exigirá autenticação e revisão.

## Alternativas

- **React + Vite:** adiado para evitar Node no primeiro start do Windows.
- **Banco em memória:** só para demo, não substitui SQLite nem recuperação após reinício.
- **LLM para todas as falas:** adiado pelo custo de CPU, latência e comportamento não determinístico.
- **Coordenadas x/y:** rejeitadas; narração não permite estimar pixels reais com confiabilidade.

## Consequências e critérios de revisão

Versão 1 do schema é independente da interface e se torna contrato para classificação, reconciliação e site. Medir latência, perda de fonte e RAM no Windows antes de promover decisões provisórias a definitivas.
