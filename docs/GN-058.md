# GN-058 — preparo de corpus rotulado pt-BR (sem material real versionado)

A ferramenta `scripts/gn058_corpus.py` valida localmente um **manifesto e anotações humanas independentes**, e produz apenas um relatório de metadados. Não baixa nem lê áudio/vídeo, não guarda texto no relatório e não valida juridicamente as permissões declaradas. **GN-058 continua [ ] até existir um corpus REAL autorizado, com registros de licença/proveniência e avaliação documentada.**

## Entradas locais (não commitar dados de terceiros)

Crie `manifest.json` com metadados de cada gravação:

~~~json
{
  "schema_version": 1,
  "dataset_id": "minha-amostra-ptbr",
  "rights_statement": "Descrever autorização específica, titular e escopo de uso",
  "independent_human_annotation": true,
  "recordings": [
    {
      "group_id": "partida-01",
      "source_ids": ["radio-01"],
      "duration_seconds": 300,
      "content_sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
      "split": "test"
    }
  ]
}
~~~

O hash acima é **ilustrativo**: substitua pelo SHA-256 do arquivo de origem efetivamente autorizado. A mesma gravação, ainda que reutilizada sob outro ID, não pode pertencer a splits diferentes. `source_ids` devem corresponder aos nomes das fontes anotadas; cada fonte listada precisa de ao menos um segmento. Agrupe gravações equivalentes na mesma divisão para impedir vazamento treino→teste. Duração por grupo ≤600 segundos; máximo de 3.000 segmentos por arquivo.

Crie `anotacoes.json` com intervalos e evidência humana independente, **sem copiar as previsões do modelo**:

~~~json
[
  {
    "group_id": "partida-01",
    "source_id": "radio-01",
    "start_seconds": 0,
    "end_seconds": 6,
    "narration_kind": "live_play",
    "team_id": null,
    "zone": null
  }
]
~~~

Campos de avaliação opcionais: `team_id`, `player_id`, `zone` (band 1–5, lane left/center/right), `event_kind`, `narration_kind`, `reference_text`. **Omitido** significa sem anotação para esse campo, enquanto `null` significa anotação negativa. IDs e categorias devem respeitar o contrato v1 de `app/contracts.py`.

Execute, em Windows ou Linux com dependências da demo:

~~~powershell
.\.venv\Scripts\python.exe -m scripts.gn058_corpus --manifest .\manifest.json --annotations .\anotacoes.json --permission-confirmed --output .\resumo-gn058.json
~~~

O CLI recusa sobrescrever o relatório, e não imprime frases, URLs ou nomes de atletas. O JSON contém somente contagens por split/campo, SHA-256 dos arquivos JSON e alertas de que direitos e qualidade **não foram verificados**. A opção `--permission-confirmed` é uma declaração do operador, não prova de autorização.

## Para concluir GN-058

Obter ao menos um conjunto de narrações próprias/licenciadas com autorização documentada, transcrições anotadas independentemente e splits por gravação; executar a validação, comparar com a saída de `scripts.gn083_audit --reference` e registrar cobertura, precisão/recall, WER quando aplicável, erros e limitações. Não publicar áudio nem transcrições sem autorização expressa. Os dados sintéticos dos testes não satisfazem esse aceite.
